# 🐾 HappyPets - Sistema de Gestión Veterinaria

**Descripción:**
HappyPets es una aplicación desarrollada en **Java** para gestionar la información básica de una veterinaria mediante un menú interactivo con **JOptionPane**.

El proyecto fue desarrollado aplicando los fundamentos de **Programación Orientada a Objetos (POO)**, organizando el código por paquetes y separando las responsabilidades mediante clases modelo y servicios.

**Funcionalidades:**

- Registro de mascotas
- Registro de dueños
- Registro de veterinarios
- Registro de citas
- Registro de tratamientos
- Visualización de la información registrada
- Arquitectura organizada por paquetes
- Uso de ArrayList para almacenar los registros

**Tecnologías:**

- Java
- JOptionPane
- POO
- ArrayList
